# 📈 个人长期成长计划 (Personal Long-Term Growth Plan)

## 1. 语言突击 (Language Surge)
**目标：雅思 7.0 (Goal: IELTS 7.0)**

> **核心策略**：碎片化输入 + 高强度刻意练习

- [ ] **词汇积累 (Vocabulary)**
    - **工具**：**不背单词 (MaiMemo)**
        - **设置**：“乱序版”，每日 80 词。
    - **辅助**：**多邻国 (Duolingo)**
        - 用于语感培养、发音纠正及基础听力热身。

- [ ] **听力专项 (Listening)**
    - **精听**：**王陆雅思王听力真题语料库**
        - 重点听写第 3、4、5 章。不求一次性 100% 正确，目标是听到单词后能形成拼写肌肉记忆，每天写满一页。
    - **泛听**：**Spotify 播客**
        - 利用通勤/琐碎时间背景播放，推荐 *All Ears English Podcast*。
    - *建议：每日英语环境浸泡时长应大于 30 分钟。*

## 2. 硬核技能 (Hard Skills)
**目标：技术栈积累与肌肉记忆**

- [ ] **盲打练习 (Touch Typing)**
    - **目标**：纠正指法，提升 WPM (每分钟字数)。
    - **平台**：Keybr (指法训练) / Monkeytype (速度提升)
    - *要求：每天 15 分钟，直到形成无意识的肌肉记忆。*

- [ ] **Python 编程 (Programming)**
    - **基础**：掌握变量、循环、函数等核心概念。
    - **进阶**：根据兴趣选择一个方向（Pandas 数据分析 / Scrapy 爬虫 / Django Web 开发）。
    - **资源**：YouTube 优质教程。

## 3. 身体重塑 (Body Reshaping)
**核心策略：三分练，七分吃补与睡眠。体能是精力的底层支撑。**

- [ ] **力量训练 (Strength Training)**
    - **四天循环制**：胸部 → 背部 → 肩部 → 腿部。
    - *原则：按顺序滚动训练，不强制固定周几，重点保证训练强度和动作质量。*

- [ ] **有氧运动 (Cardio)**
    - 安排在休息日或力量训练后，每周 1-2 次。

- [ ] **恢复与作息 (Recovery)**
    - [ ] **拒绝熬夜**：保证深度睡眠以促进肌肉修复和激素分泌。
    - [ ] **饮食控制**：高蛋白饮食，减少精制碳水摄入（防止饭后昏睡）。

---

## 4. 自律与心态管理 (Mind Management)
**核心策略：做减法，夺回专注力。**

- [ ] **多巴胺排毒 (Dopamine Detox)**
    - **减少 (Avoid)**：
        - 限制短视频（TikTok/抖音/视频号）使用时间。
        - 减少无目的的社交媒体刷新。
        - 睡前和醒后 30 分钟内严禁触碰手机。
    - **替代 (Replace)**：
        - 冥想 / 正念呼吸训练。
        - 阅读纸质书籍。
    - *目的：通过接受“无聊”，提升大脑对高难度任务（学英语、写代码）的耐受力。*
